# IMS Common Cartridge 1.3 XSD

이 디렉터리의 XSD 파일은 **1EdTech Consortium(구 IMS Global Learning Consortium)** 이
공개한 IMS Common Cartridge 1.3 및 Assignment Extension 공식 스키마를 수정 없이 그대로
복사한 것입니다. 이 저장소는 이 파일들을 **로컬 적합성 검증**에만 사용합니다.

- 라이선스 안내: https://www.imsglobal.org/license.html
- 원본 배포처: https://www.imsglobal.org/cc
